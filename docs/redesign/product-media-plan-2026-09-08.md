# CVS Radar: product media and next front-end decisions

Decision draft · 2026-09-08 · Planning only

**Recommendation:** fix misleading date/ranking cues and mobile identification first. Keep the shelf text-first. Evaluate a bounded, rights-cleared photo pilot in expanded cards; show nutrition only for an exact, dated package version with verified units. Neither feature is a catalog-wide launch commitment.

## Evidence and decision conventions

- **OBSERVED** means source inspection or a read-only aggregate of local artifacts. Repository citations are `file:line`; a collection-start citation on an aggregate identifies the collection being queried, not a claim that its first record alone proves the count.
- **INFERENCE (high/medium/low confidence)** marks outside-world judgments and estimates, including estimates informed by the linked primary sources checked on 2026-09-08. These are not measured CVS Radar coverage or vendor quotes.
- **PROPOSAL** marks choices for the owner, not current behavior. All proposals have IDs; Part D assigns each ID to exactly one bucket. Operational requirements under an ID belong to that same proposal.
- **UNVERIFIED** identifies a missing fact and the evidence needed to settle it. This is a source/CSS audit, not a production browser or user test. Actual clipping, keyboard behavior on devices, layout heights and traffic are UNVERIFIED; settle with the browser checks in Part D. No application code, build, pipeline run, dependency installation or existing-file changes are part of this round.

### Cost model shared by the routes

**INFERENCE (medium confidence on byte budgets; high on arithmetic):** use decimal KB/MB/GB. Budget one 160px derivative at 24KB and one 640px derivative at 120KB per accepted photo. ### C4 — PROPOSAL: a verified package-facts pilot, separate from taste evidence

**Worth showing:** energy (kcal), protein (g), sugars (g), sodium (mg), with an explicit **per package** basis when conversion is verified. For a multipack use the individual retail/consumption unit only if clearly documented, labeled “每小包”; never silently treat the entire five-pack as one meal. Preserve a per-serving display when the package count is unknown and label it visibly; never compare it as per-package.

**Layout and mobile:** no nutrition numbers or empty nutrition tiles on collapsed cards in this round. In expanded detail, put a compact “包裝營養” block **after author/evidence and before source links**, visually separate from taste consensus (current section order: `web/components/ProductDetail.tsx:45`, `web/components/ProductDetail.tsx:70`, `web/components/ProductDetail.tsx:90`). **All missing states:**
